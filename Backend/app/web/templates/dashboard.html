What This App Covers

Operational snapshot

This system stores each patient record as a cryptographically linked block. Every block preserves the previous hash, making unauthorized edits visible during validation.

Persistent ledger Loads from and saves to JSON automatically on startup and change.
Hash strategy support Uses SHA-256 by default and can switch algorithms through the strategy layer.
Tamper visibility Validation detects both broken links and mismatched recalculated hashes.
